# VisionBI - Data Insights & Analytics

A modern, responsive web application for data insights and business intelligence solutions. Built with cutting-edge technologies to deliver professional analytics experiences.

## 🚀 Features

- **Modern UI/UX**: Built with React and shadcn/ui components
- **Responsive Design**: Fully responsive design that works on all devices
- **Fast Performance**: Powered by Vite for lightning-fast development and builds
- **Type Safety**: Written in TypeScript for better code quality
- **Modern Styling**: Styled with Tailwind CSS for rapid UI development

## 🛠️ Technologies Used

This project is built with:

- **React 18** - Modern React with hooks and latest features
- **TypeScript** - Type-safe JavaScript for better development experience
- **Vite** - Next generation frontend tooling for faster builds
- **Tailwind CSS** - Utility-first CSS framework
- **shadcn/ui** - High-quality, accessible React components
- **Lucide React** - Beautiful & consistent icon toolkit

## 📦 Installation & Setup

Make sure you have Node.js installed on your machine.

```bash
# Clone the repository
git clone <your-repo-url>

# Navigate to project directory
cd visionbi-data-insights

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎯 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint for code quality
